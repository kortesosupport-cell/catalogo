# Données de démonstration

Toutes les données affichées par l'application en phase 1 vivent dans ce
dossier. Elles sont **entièrement fictives** : les cliniques, les personnes,
les numéros de téléphone (série réservée 555‑01XX), les courriels et les
transcriptions n'existent pas et ne correspondent à aucune entreprise ni à
aucun patient réel. Aucune information médicale ou diagnostique n'y figure.

En phase 2, ce dossier sera remplacé par une couche d'accès à la base de
données (Supabase). Les pages consomment uniquement les types de
`src/types`, donc la migration se fera sans réécrire l'interface.
