Note de compatibilité technique
Cette signature utilise un gabarit HTML tabulaire (structure <table>) conforme aux exigences d'Outlook 2016–2021 et Microsoft 365. La bordure dorée verticale est rendue via la propriété CSS border-right de la cellule de gauche. Pour l'installation dans Gmail : coller le code HTML via les paramètres Signature avancée. Pour Outlook : utiliser le module Signatures dans les options de messagerie et coller en mode HTML. Les polices Google Fonts sont déclarées en fallback sécurisé (Georgia, Arial).

Outlook / O365

Gmail / Google Workspace
Paramètres → Voir tous les paramètres → Signature. Coller en mode source. Compatible mobile.
Apple Mail / Thunderbird
Compatible via glisser-déposer du fichier .htm dans le champ de signature HTML de l'application.
